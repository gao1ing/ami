# AMI 用电数据查询与设备监控

## 1. 环境

- 开发与构建：JDK 17、Maven 3.9。
- 后端框架：Spring Boot 3.5.7、MyBatis-Plus 3.5.14。
- 数据库：MySQL 8.4，默认连接本机 3306 端口的 `ami_demo` 库。
- 缓存：Redis 默认使用本机 6379 端口，Caffeine 随应用运行。

## 2. 代码说明

1. **用电数据查询**：使用 MyBatis 动态 SQL，按设备编号、时间范围、曲线类型和用量上下限组合查询，支持分页。用量指电表在一个 15 分钟区间内的输入电量，单位为 kWh。
2. **曲线查询缓存**：按设备和当地日期缓存日曲线。先查 Caffeine，再查 Redis，两层都未命中时查询 MySQL。Caffeine 缓存 30 秒，Redis 缓存 2 分钟，空结果只在 Redis 保留 10 秒。读数补正提交后，清理该设备当天的缓存。
3. **核心查询优化**：`scripts/step4` 提供样例数据、执行计划和索引 SQL，用于比较跨设备用量查询在添加 `(curve_type, sample_time, device_id)` 联合索引前后的扫描行数。
4. **设备状态同步与监控**：使用 Spring 定时任务分批处理待同步的心跳记录，按平台最近接收心跳的时间判断设备是否离线。接口支持查看设备状态，以及统计在线、离线和从未上报的设备数量。
